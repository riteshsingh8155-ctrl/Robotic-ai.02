# Robotic-ai.02

Angel One + SMC/ICT Trading Bot with Telegram Alerts

## Setup
1. Install packages: `pip install -r requirements.txt`
2. GitHub Secrets me ye 6 keys dalo: `API_KEY`, `CLIENT_CODE`, `PASSWORD`, `TOTP_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
3. Run: `python Main.py`

## Files
- `Main.py` = Bot ka main code
- `requirements.txt` = Packages ki list
